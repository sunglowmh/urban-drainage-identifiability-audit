- 判读 (预登记 §1.1 阈值): 留出预测 CRPS 改善 ≥5% 的事件比例作为 C1 '预测相关' 轴证据; 改善率普遍 <5% 或 ≤0 → 参数学习对预测分布的增益被误差结构底噪主导, '可辨识 ≠ 预测有用' 的区分进一步坐实
- T4 空间迁移代价: ΔCRPS ≈ 0 → 校准信息空间可迁移 (spatial generalization 成立); ΔCRPS >> 0 → 簇级泛化损失; 簇7 (边界单站) 单列解读 (A17-1)
