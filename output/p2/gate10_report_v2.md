## T4 全局结论：C1–C4 证据映射与核心命题

证据链（预登记编号）→ 终分类贡献：

| 关口 | 证据 | 对分类的贡献 |
|---|---|---|
| 关口 5–6（I9–I12） | 孪生 v3 MARGINAL 放行；C1–C4 阈值冻结（A25） | 判级轴工作阈值 R_j≥0.5 / KL≥0.1 合法化 |
| 关口 7（I15–I16） | 误差结构 > 强迫口径 > 事件信息量；扰动臂 E1/E2 崩塌 | A3 轴翻转来源；判级对口径修正稳健 |
| 关口 8（I17） | 边界堆积=低激发下误差结构混淆不可分辨；簇 bootstrap E1/E2 脆弱 | A4/A5 轴；"判级稳定=伪可辨识"佐证 |
| 关口 9（I18–I19） | LOEO 预测改善 0/33 达标；判级 33/33 全过；空间迁移零代价 | A6/A7 轴；C1 预测轴 FAIL 的直接证据 |
| **关口 10（本报告）** | 翻转矩阵 7 轴机械化汇总 | **终分类：33/33 C2** |

**核心命题（贯穿关口 7–9）**：误差结构决定判级稳定性与后验位置（跨模型漂移中位 1.7–26.7σ），但不决定预测分布（预测 CRPS 跨模型极差 ≤8%）；校准的预测增益低于误差底噪（W 尺度 0.054–0.104 m）。**可辨识 ≠ 预测有用**在 C1–C4 语言下的表述：判级轴全部落入 C2，且 C2 的"条件"（误差模型选择、事件信息量、网络采样）本身被证明是判级不稳定性的来源，而非预测增益的来源。

**对论文的处置含义**：C1（稳健可辨识且预测相关）不成立 → 按预注册叙事，主结论应表述为"**条件可辨识性受误差结构支配且预测价值有限**"：θ 的后验对误差模型设定高度敏感（均值漂移与判级翻转），而该敏感性不传导到预测分布——这意味着（i）以判级/后验位置为核心的率定报告不足以为预测精度背书；（ii）预测层的实用价值必须由独立于误差结构的证据（如 W 底噪量级）界定。
